# Drop new pages here

When you have a new page or a new version of a page for www.ryzo.studio
(for example, The Dial page):

1. **Put the file in this folder**: the zip or HTML file, exactly as you received it.
   You don't need to unzip it or rename anything.
2. **Tell Claude** what it's for, for example *"publish The Dial page"*.

Claude takes it from there: it puts the page in the right place, checks it, and
publishes it. A minute or two later it's live.

Files you drop here are never published or uploaded to GitHub. Only this note is.
